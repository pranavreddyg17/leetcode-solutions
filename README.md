# LeetCode Solutions

My Python practice solutions for data structures and algorithms. Each problem directory contains its statement and solution.

## Browse

Directories use the problem slug supplied by the original sync tool. Some numeric prefixes are internal IDs rather than the public problem number; use the statement link inside each folder to identify the problem.

Examples:

- [Two Sum](1-two-sum/): hash maps.
- [Valid Parentheses](20-valid-parentheses/): stacks.
- [Reverse Linked List](206-reverse-linked-list/): linked lists.
- [Same Tree](100-same-tree/): tree traversal.
- [Product of Array Except Self](238-product-of-array-except-self/): prefix/suffix products.

## Usage

These files target LeetCode's Python judge. Some rely on types or imports supplied by that environment and are not standalone command-line programs. Open the problem README, follow its LeetCode link, and run the solution with the platform's test cases.
